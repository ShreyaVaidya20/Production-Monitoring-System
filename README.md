# Production-Monitoring-System
Production Monitoring System is a Flutter-based mobile application developed for real-time monitoring of industrial machine production data. The app displays live production counts, machine status, alarms, and reports using RESTful APIs, helping operators and supervisors monitor factory operations efficiently.


# Project Overview
A real-time industrial production monitoring mobile application developed using Flutter and Dart. The app enables operators and supervisors to monitor live machine production counts, machine status, alarms, and reports directly from mobile devices.

## Features
* Real-time production monitoring
* Machine-wise dashboard
* Live API-based updates
* Local notifications for production milestones
* Secure login and session management
* Alarm and report modules
* Responsive Flutter UI

## Tech Stack
* Flutter
* Dart
* RESTful APIs
